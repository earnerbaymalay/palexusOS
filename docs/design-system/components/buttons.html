Accessibility Notes

  • All buttons have visible focus indicators (2px Electric Mauve outline)
  • Icon-only buttons include aria-label attributes
  • Buttons meet WCAG AA contrast requirements (11.3:1 Mauve on Obsidian)
  • Minimum 44×44px touch target area maintained
  • Disabled state uses opacity reduction with cursor: not-allowed
  • Keyboard navigation supported via Tab key

CSS Implementation

/* Basic button styles */
.btn {
  padding: var(--space-2) var(--space-4);
  border-radius: var(--radius-md);
  font-family: var(--font-mono);
  cursor: pointer;
  transition: all var(--transition-quick);
}

.btn:focus {
  outline: 2px solid var(--color-electric-mauve);
  outline-offset: 2px;
  box-shadow: var(--shadow-glow-mauve);

.btn-primary {

  color: var(--color-smoked-obsidian);

.btn-primary:hover:not(:disabled) {

  box-shadow: var(--shadow-md);
